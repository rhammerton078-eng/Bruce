4 · Memory & storage controlBuilt in this round

⚠️ Storage warnings
  • Live DB size + free disk in the status bar
  • Warning and critical levels you choose
  • Uploads pause automatically when the disk is nearly full
  • Checks PHP / MySQL limits and tells you exactly what to change
💾 Download & restore
  • Back up the database anytime (.sql.gz)
  • Full backup: database + original files (.zip)
  • Restore from a file, even on another PC
  • Automatic nightly backup, keeps the last 14
  • Export knowledge as Markdown or graph JSON
🗑 Delete memory
  • Forget one source or one concept
  • Delete chat history / taught facts
  • Reset the graph and re-learn from sources
  • Delete ALL memory, back to zero knowledge
  • Type DELETE to confirm, with a safety backup first

5 · Offline desktop software

One-click start
  • launcher\Create Desktop Shortcut.bat adds an ATLAS icon to your desktop
  • The icon starts MySQL, Apache, Ollama and the background learner
  • It opens ATLAS in its own app window (Edge / Chrome app mode)
  • Stop ATLAS.bat shuts everything down
Installable app
  • Browser menu → “Install ATLAS” to pin it to the Start menu and taskbar
  • Cached app shell, so it opens instantly
  • No internet needed after you download the models
  • Only answers your own PC unless you allow LAN access

6 · Roadmap

Phase 1–3 · Core Done

Upload → read → embed → graph → cited chat. 2D/3D explorer, path finder, timeline, overview, sleep cycle, teaching commands, time travel.

Memory & offline Done

Storage monitor and warnings, limits checker, backup / download / restore, memory wipe, re-embed, index rebuild, dedicated DB user, launchers, installable app.

Memory cards Done

One MySQL database per card. Insert, eject (to a single password-protectable file), switch, blank card. Move Mnemo's memory between PCs like a memory card in a phone.

Baby mode Done

Strict "knows only what you taught" answers, endless levels from Newborn onward, Mnemo's curiosity questions, lessons with graded exams, a growth diary, optional forgetting.

Tutorial mode Done

Learn hub with 9 guided spotlight chapters, a self-checking 12-task checklist, a demo knowledge pack with a built-in contradiction, a ? help button on every screen, and a first-run welcome.

Phase 5 · Truth engine Done

  • claims + contradictions: detect disagreeing sources
  • fact_versions: full history of every fact
  • Review queue for low-confidence facts
  • Duplicate-concept merge (with undo)

Phase 6 · Self-improvement Done

  • Golden test set, scored nightly (is Mnemo improving?)
  • Self-quiz on new material
  • Reuse approved answers (qa_memory)

Phase 7 · Assistant features Done

  • Standing questions, re-answered when knowledge changes
  • Quiz / flashcard mode, where Mnemo teaches you back
  • Hypothesis suggestions (“these ideas may be connected”)
  • Audio and video via local Whisper (ffmpeg + whisper.cpp)

Phase 8 · Scale Done

  • Image-to-image similarity (visual hash + meaning) and search by image
  • MariaDB 11.7+ native vector index (one-click, optional)
  • Training-data export + LoRA fine-tune guide (docs/finetune.html)

FeedingStart with foundational material (overviews, textbooks, glossaries), then specifics. Use a collection per subject.
