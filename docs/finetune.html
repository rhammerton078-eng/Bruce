Fine-tuning Mnemo (optional, Phase 8)

Mnemo already learns every day through its MySQL memory, with no training needed. Fine-tuning goes one step further: it teaches the model itself your style, vocabulary and verified answers. Do it monthly, once you have a few hundred approved answers.

Requirements: an NVIDIA GPU with 8 GB+ VRAM, Python 3.10+, and roughly 30–60 minutes. Everything still runs offline after the one-time install.

1 · Export your verified knowledge

In ATLAS → Quality → Training data (.jsonl). The file contains approved answers (👍), your benchmark questions, taught facts and flashcards you've reviewed, in the standard chat format.

2 · Train a LoRA adapter (Unsloth)

pip install unsloth datasets trl
from unsloth import FastLanguageModel
from datasets import load_dataset
from trl import SFTTrainer, SFTConfig

model, tok = FastLanguageModel.from_pretrained("unsloth/Qwen2.5-7B-Instruct", max_seq_length=4096, load_in_4bit=True)
model = FastLanguageModel.get_peft_model(model, r=16, lora_alpha=16,
          target_modules=["q_proj","k_proj","v_proj","o_proj","gate_proj","up_proj","down_proj"])

ds = load_dataset("json", data_files="mnemo-training.jsonl", split="train")
ds = ds.map(lambda x: {"text": tok.apply_chat_template(x["messages"], tokenize=False)})

SFTTrainer(model=model, tokenizer=tok, train_dataset=ds,
           args=SFTConfig(dataset_text_field="text", per_device_train_batch_size=2, gradient_accumulation_steps=4,
                          num_train_epochs=2, learning_rate=2e-4, output_dir="out")).train()

model.save_pretrained_gguf("mnemo-gguf", tok, quantization_method="q4_k_m")

3 · Load it into Ollama

Create a file named Modelfile next to the generated .gguf:

FROM ./mnemo-gguf/unsloth.Q4_K_M.gguf
PARAMETER temperature 0.2
SYSTEM "You are Mnemo, a helpful assistant that answers from the user's personal knowledge base."
ollama create mnemo -f Modelfile

Then in ATLAS → Settings, choose mnemo as the chat model.

4 · Check it really improved

Run the benchmark in ATLAS → Quality before and after switching models. Keep the fine-tuned model only if the score goes up. That comparison is also a strong, measurable result for a thesis.

Keep the embedding model unchanged. Fine-tuning only replaces the chat model, so the memory and vectors stay valid.
